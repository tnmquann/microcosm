Parameters¶

Every parameter of microcosm, generated from nextflow_schema.json (the same file Nextflow validates your run against). Give them on the command line (--name value) or in a -params-file. Run nextflow run tnmquann/microcosm -r 2.0.0 --help for the same list in the terminal.

Tip

Use the search box (top right) or your browser search to find a parameter. Booleans can be given as --flag (true) or --flag false.

Input/output options¶

Define where the pipeline should find input data and save output data.

Parameter

Type

Default

Description

--input

string

Path to an input CSV file with a required non-empty sample_id column, or a directory containing paired FASTQ files. Optional only when --genome_input is supplied.

--outdir

string

./results

The output directory where results will be saved

--input_format

string

csv

Format of input files. Choices: csv, directory.

--publish_dir_mode

string

copy

Method used to save pipeline results. Choices: symlink, rellink, link, copy, copyNoFollow, move.

--assembly_input

string

Path to CSV file containing pre-computed assemblies (optional). Skips preprocessing and assembly steps. Required columns: sample_id, run_id, group, assembler, fasta more

--genome_input

string

Standalone genome CSV for bacterial downstream analysis. Required headers: sample_id,fasta. Optional headers: run_id,group,assembler,lineage. more
--assembly_input

When supplied, only binning and downstream workflows are run. Must be used with --input_format csv. Reads must also be provided via --input parameter

--genome_input

Rows with a valid GTDB-style lineage bypass classification. Rows with blank lineage are classified through BIN_CLASSIFICATION and need its database inputs (--sourmash_database and --sourmash_taxonomy_csv, or --bin_classifier gtdbtk with --gtdbtk_db). This input is mutually exclusive with --input and --assembly_input.

--amrfinderplus_db

Optional. When unset, amrfinder_update downloads the current database into the run work directory. A database made for AMRFinderPlus 3.x is not compatible.

--save_amrfinderplus_db

Used only when the pipeline downloads it (no local path given). Pass the saved folder on later runs to skip the download; set false to keep it only in the work directory.

--amrfinderplus_args

Default --plus as in 5_amr.sh. Replaces the default when set, so keep --plus if you want it. --organism is added per genome from --amrfinderplus_organism_map.

--amrfinderplus_organism_map

Columns lineage_pattern, organism. The first row whose lineage_pattern occurs in the genome lineage wins; no match = no --organism. GTDB suffixes such as _B are ignored when matching (s__Enterococcus_B faecium matches s__Enterococcus faecium). Default: assets/amrfinderplus_organisms.tsv (the 5_amr.sh list).

--abricate_db

Leave unset to use the database bundled with the installed ABRicate container. When set, the directory must contain --abricate_db_id.

--rgi_main_args

Default as in 5_amr.sh. --input_type contig and --local are always added.

--resfinder_db

Optional. When resfinder_db, pointfinder_db or disinfinder_db is unset, the missing ones are downloaded at tag resfinder-4.7.2 into the run work directory.

--save_resfinder_db

Used only when the pipeline downloads it (no local path given). Pass the saved folder on later runs to skip the download; set false to keep it only in the work directory.

--resfinder_args

Default as in 5_amr.sh. --point --species is added when the genome species or genus has a PointFinder folder.

--pointfinder_db

Optional; downloaded when unset. PointFinder runs when the genome species (else genus) has a folder in this database, as in 5_amr.sh.

--disinfinder_db

Optional; downloaded at tag resfinder-4.7.2 when unset.

--deeparg_db

Optional. When unset, deeparg download_data fetches it into the run work directory (about 1 GB, slow).

--save_deeparg_db

Used only when the pipeline downloads it (no local path given). Pass the saved folder on later runs to skip the download; set false to keep it only in the work directory.

--virulencefinder_db

Optional. When unset, virulencefinder_db is downloaded at a fixed revision into the run work directory.

--save_virulencefinder_db

Used only when the pipeline downloads it (no local path given). Pass the saved folder on later runs to skip the download; set false to keep it only in the work directory.

--kleborate_preset_map

Columns lineage_pattern, preset (may be empty), modules. The first row whose lineage_pattern occurs in the genome lineage wins; genomes with no match skip Kleborate. GTDB suffixes such as _B are ignored when matching (s__Enterococcus_B faecium matches s__Enterococcus faecium). Default: assets/kleborate_presets.tsv (the 3_kleb.sh rules).

--bacterial_decision_table

Optional: without it every d__Bacteria genome follows the default route. Columns: lineage_pattern, optional label, then any of amrfinderplus, abricate, rgi, resfinder, deeparg, mlst, virulencefinder, plasmidfinder, kleborate, sistr, seqsero2, genotyphi, paratype with y or n. lineage_pattern is one or more whole GTDB taxa at any rank (p__Bacillota, g__Salmonella, s__Escherichia coli; GTDB suffixes such as B are ignored). The most specific matching row decides its y/n steps (species over genus over phylum, whatever the row order); blank cells, missing columns and lineages with no row follow the default route. --skip still turns a tool off for every genome. kleborate=y also needs a --kleborate_preset_map row; genotyphi/paratype=y still need the SISTR serovar route. Optional parameter columns, per genome of the matched row: amrfinderplus_args, abricate_args, rgi_main_args, resfinder_args, deeparg_args, mlst_args, virulencefinder_args, plasmidfinder_args, kleborate_args, sistr_args, seqsero2_args, mykrobe_args, paratype_args (a non-blank cell replaces the -- parameter, e.g. mlst_args '--scheme ecoli_achtman_4'), amrfinderplus_organism (replaces the --amrfinderplus_organism_map value) and resfinder_species (PointFinder species folder, e.g. escherichia_coli). Example: assets/bacterial_decision_table_example.tsv.

--seqsero2_args

Default as in 4_sal.sh (k-mer mode, assembly input).

--paratype_bundle

Used only for genomes whose SISTR serovar is Paratyphi A. If not set, Paratype is cloned at a fixed commit when such a genome is found. The directory must contain paratype.py, SParatyphiAKU12601.fasta, SParatyphiA_genotype_specific_alleles.txt and SParatyphiA_gene_mutation_codons.txt; it is copied into each task and never modified.

--save_paratype_db

Used only when the pipeline downloads it (no local path given). Pass the saved folder on later runs to skip the download; set false to keep it only in the work directory.

Workflow options¶

Options controlling which workflows to run

Parameter

Type

Default

Description

--enable_readbase

boolean

false

Run the read-based profiling subworkflow instead of assembly-based

--enable_singlesketch

boolean

false

Enable per-sample processing mode using SOURMASH_SKETCH and SOURMASH_GATHER instead of batch processing with SOURMASH_MANYSKETCH and SOURMASH_FASTMULTIGATHER. Useful for HPC environments where per-sample job control is needed.

--enable_bacterial_downstream

boolean

false

Route assembly-produced bins with resolved d__Bacteria lineage into bacterial downstream analysis. more

--readbased_taxotools

string

microcosm

Read-based profiler(s): microcosm (sourmash + YACHT), sylph, or microcosm,sylph more

--readbased_postprocess

string

Optional post-processing mode for merged read-based results. Requires enable_readbase. The all mode creates default, phyloseq, and taxburst outputs and also collects RGI-BWT outputs when enable_rgi_bwt is enabled. Choices: all, phyloseq, taxburst, rgi_bwt. more

--readbased_postprocess_options

string

--min_coverage 0.05

Additional supported command-line options passed safely to bin/py_scripts/read_based/post_processing.py. Defaults to filtering YACHT results at min_coverage 0.05. more

--enable_rgi_bwt

boolean

false

Enable RGI BWT analysis for antimicrobial resistance genes
--enable_bacterial_downstream

This switch is for the ordinary assembly/binning route. Supplying --genome_input activates the same downstream routing contract automatically.

--readbased_taxotools

sylph profiles the paired reads directly (no read merging) and writes to Readbased_Analysis/sylph/. With both, each tool keeps its own output folder. --enable_singlesketch only changes the microcosm branch.

--readbased_postprocess

Valid values: all, phyloseq, taxburst, rgi_bwt. default and taxburst use the microcosm (sourmash + YACHT) result; phyloseq also works with sylph (--enable_sylphtax). The rgi_bwt mode collects the RGI-BWT folders of all samples, needs --enable_rgi_bwt and works with either profiler. With all and RGI-BWT disabled, only the RGI-BWT output is skipped and the pipeline continues with a warning.

--readbased_postprocess_options

Default: --min_coverage 0.05. Override this string to use another supported threshold or option, such as --min_coverage 0.1 --use_average. Module-managed input, input_format, output, and output_format arguments cannot be overridden. Options must be compatible with every selected output mode (--remove_unclassified is not passed to taxburst, which already leaves unclassified out). The microcosm MultiQC section follows the same --min_coverage and --remove_unclassified (Unclassified left out, taxa rescaled to 100 %).

--bin_classifier

sourmash sketches the bins and runs gather + tax genome against --sourmash_database / --sourmash_taxonomy_csv. gtdbtk runs GTDB-Tk classify_wf against --gtdbtk_db instead (one call per sample; --genome_input rows without lineage in one call). Both give GTDB lineages to the bacterial downstream routing, --bacterial_decision_table and MultiQC; GTDB-Tk 'Unclassified Bacteria' bins (too few markers) are routed as d__Bacteria, plain 'Unclassified' and failed bins as unresolved. Results: Taxonomy/sourmash/ or Taxonomy/GTDB-Tk/.

--gtdbtk_db

Unpacked GTDB-Tk reference data for GTDB-Tk 2.5.2 (GTDB release226; read only), e.g. --gtdbtk_db /path/to/gtdb/release226 (the folder that contains metadata/, markers/, skani/ ...).

--gtdbtk_args

Added after --extension and --pplacer_cpus, e.g. '--min_perc_aa 10 --min_af 0.65' (GTDB-Tk defaults) or '--skip_ani_screen'.

--sylph_datatype

taxonomic_abundance uses sylph-tax relative_abundance; sequence_abundance runs sylph profile with --estimate-read-counts and uses the estimated read counts.

--enable_sylphtax

Writes per-sample *.sylphmpa, a merged clade x sample table, and with --readbased_postprocess phyloseq/all the phyloseq tables (tax_table.csv, otu_table.csv, sample_data.csv).

--sylph_taxonomy

One metadata file per sylph database (the pipeline stops when the counts differ), all passed to one sylph-tax taxprof call (-t). Example for --sylph_database gtdb-r226-c200-dbv2.syl2db,fungi-refseq-2025-10-11-c200-dbv1.syldb: --sylph_taxonomy gtdb_r226_metadata.tsv.gz,fungi_refseq_2025-10-11_metadata.tsv.gz.
