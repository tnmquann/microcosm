Where are the main results?¶

Result

Folder

Report of the whole run

Readbased_Analysis/sylph/

phyloseq / taxburst / standard tables

Readbased_Analysis/rgi_bwt/

ContigsAnalysis/

Bins (MAGs) and their QC

Binning/<binner or refiner>/, Binning/QC/

Taxonomy/

Bacterial_Analysis/ (one summary/<prefix>_<tool>.tsv per tool)

Tool versions, execution report

pipeline_info/

Downloaded databases (for reuse)

Databases/

<prefix> is the last folder name of --outdir.
