Citation, authors and license¶

Citing microcosm¶

If you use microcosm, please cite:

Minh-Quan T.N., Nguyen M.T.S. (2025). microcosm: A Nextflow pipeline for comprehensive analysis of short-read metagenomic data using sourmash and YACHT.

Please also cite the tools you used: pipeline_info/microcosm_software_versions.yml lists every tool and version of your run, and the MultiQC report lists the tool citations.
