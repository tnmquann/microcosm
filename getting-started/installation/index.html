Installation¶

microcosm runs with Nextflow and gets every tool from containers or Conda: you install Nextflow and one software runtime, then the databases you need (Databases).

Software¶

  • Nextflow version 26.04.0 or later (required since microcosm 2.0.0, which uses the Nextflow strict syntax)

  • Java (version 16 to 22, required by Nextflow)

  • Conda and/or Mamba for package and environment management.

  • Optional: A container runtime engine like Docker or Apptainer.

Hardware¶

  • A POSIX-compatible operating system (e.g., Linux, macOS) or Windows with WSL. We strongly recommend using a Unix-based OS for best compatibility with all tools.

  • At least 32 GB of RAM for MEGAHIT, or 128 GB if you plan to use metaSPAdes for assembly.

  • At least 256 GB of disk space.

    ℹ️ Storage Estimates (based on shallow shotgun metagenomics):

    • Nextflow installation: ~150 MB

    • Databases: ~120 GB

    • Environment folder: ~20 GB

    • Intermediate/cache files: 20–50 GB (varies with sample size and quality)

    • Output per sample: ~9 GB

  • Optional: Some steps in assembly-based analysis (for example, COMEBin in the binning step) will run faster if your system is equipped with a GPU.

Install the pipeline¶

1. Clone the Pipeline¶

git clone --single-branch --branch main https://github.com/tnmquann/microcosm.git

  • Or download the latest release.

  • Or use this command to download and unzip in one step:

nextflow pull tnmquann/microcosm
# Use this command to check pipeline info (if necessary)
nextflow info tnmquann/microcosm

2. Install Nextflow¶

a. Check Java installation:

java -version

If missing, follow Java install instructions.

b. Download Nextflow:

curl -s https://get.nextflow.io | bash
chmod +x nextflow

c. (Optional) Move Nextflow to your $PATH:

sudo mv nextflow /usr/local/bin

d. Test Nextflow:

nextflow info

3. Install Conda/Mamba¶

  • Mamba (Recommended): Install via Miniforge.

  • Conda: Install guide.

4. Install Container runtime (Optional)¶

  • Apptainer: Install guide. Users are recommended to use the unprivileged version to avoid unexpected errors.

  • Docker: Install guide
