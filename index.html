microcosm¶

Short-read metagenomics, from reads to typed bacterial genomes

A modular Nextflow pipeline for Illumina shotgun metagenomes: fast read-based profiling, genome-resolved analysis, bacterial typing and AMR screening, and one MultiQC report for the whole run. Built for molecular epidemiology, tuned for modest hardware.

Note

microcosm 2.0.0 is the first release under the new name (formerly metaflow). It adds sylph profiling, read-based post-processing, a full bacterial typing and AMR layer, GTDB-Tk and one MultiQC report. Coming from 1.x? Read Upgrading from metaflow 1.x.

What microcosm does¶

Read-based profiling

sourmash + YACHT (default) or sylph (+ sylph-tax), or both. AMR genes on reads with RGI bwt. Ready-to-use phyloseq and taxburst tables.

Read-based analysis
Genome-resolved metagenomics

MEGAHIT / metaSPAdes, contig analysis (geNomad, Tiara, skani), six binners with Binette / DAS Tool refinement, CheckM2, CheckM, BUSCO, GUNC, sourmash or GTDB-Tk taxonomy.

Assembly and contig analysis
Bacterial genome analysis

MLST, VirulenceFinder, PlasmidFinder; AMRFinderPlus, ABRicate, RGI, ResFinder, DeepARG harmonised with hAMRonization + ARGnorm; Kleborate; SISTR, SeqSero2, GenoTyphi, Paratype. On MAGs or your own genomes.

Bacterial genome analysis
One report per run

A MultiQC report from read QC to typed genomes, with every tool version and a summary of the parameters you changed.

Quick taste¶

nextflow run tnmquann/microcosm -r 2.0.0 -profile singularity \
    --input samples.csv --outdir project_A --enable_readbase \
    --sourmash_database /db/gtdb-rs226-reps.k31.rocksdb --sourmash_taxonomy_csv /db/gtdb-rs226.lineages.csv \
    --yacht_database /db/yacht_k31.json --enable_rgi_bwt --readbased_postprocess all

Then open project_A/MultiQC/project_A_multiqc_report.html.
